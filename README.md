# EscapeHub — Το Τελευταίο Σήμα

Συνεργατικό point-and-click μυστήριο σε απομονωμένο φάρο.
Εξερευνήστε τρεις διαδρομές, συνδυάστε τα ευρήματα και ανάψτε ξανά το φως.

## Εκτέλεση με Docker

Με εγκατεστημένο Docker, τρέξε το δημόσιο image του demo από το GitHub Container Registry. Η λήψη γίνεται χωρίς σύνδεση στο GitHub.

```sh
docker run --rm --pull always -p 127.0.0.1:8080:8080 \
  -v escapehub-accounts:/var/lib/escapehub ghcr.io/panteliszara/escapehub:latest
```

Εναλλακτικά, από τον φάκελο που περιέχει το `compose.yaml`:

```sh
docker compose up --pull always
```

Άνοιξε `http://127.0.0.1:8080` και επίλεξε την αποστολή από τον κατάλογο. Για να δοκιμάσεις δεύτερο παίκτη στον ίδιο υπολογιστή, άνοιξε `http://localhost:8080` και χρησιμοποίησε τον ίδιο κωδικό δωματίου. Τερμάτισε την εκτέλεση με `Ctrl+C`. Το image περιέχει τη Java και τα αρχεία του παιχνιδιού. Το demo λειτουργεί χωρίς βάση δεδομένων και διατηρεί την πρόοδο στη μνήμη του container.

Το CI δημοσιεύει το `latest` από το `main`. Για συγκεκριμένη έκδοση, αντικατάστησε το `latest` με το δημοσιευμένο tag της ή όρισε το αντίστοιχο image μέσω του `ESCAPEHUB_IMAGE` στο Compose. Αν η πόρτα 8080 χρησιμοποιείται ήδη, όρισε άλλη με `ESCAPEHUB_PORT=8081 docker compose up --pull always` και άνοιξε την ίδια πόρτα στον browser.

Το CI δημοσιεύει image για `linux/amd64`. Σε ARM με διαθέσιμη εξομοίωση, πρόσθεσε `--platform linux/amd64` στο `docker run` ή όρισε `DOCKER_DEFAULT_PLATFORM=linux/amd64` πριν το `docker compose up`.

Στο κάτω δεξί μέρος του παιχνιδιού εμφανίζονται η έκδοση και το commit του build. Τα images από το `main` εμφανίζουν την έκδοση του Maven και τα images έκδοσης εμφανίζουν την έκδοση του tag.

## Ανάπτυξη χωρίς Docker

Java 21. Build, tests και static analysis:

Για linux:
```sh
mkdir -p .cache/tmp
MAVEN_USER_HOME="$PWD/.cache/maven-user-home" TMPDIR="$PWD/.cache/tmp" ./mvnw "-Descapehub.build.revision=$(git rev-parse HEAD)" verify
```
Για windows:
```sh
mkdir -p .cache/tmp
.\mvnw.cmd "-Descapehub.build.revision=$(git rev-parse HEAD)" verify
```

Τοπικό demo:

```sh
java "-Djava.io.tmpdir=.cache/tmp" -cp target/classes gr.escapehub.web.DemoServer
```

1. Άνοιξε `http://127.0.0.1:8080`, επίλεξε «Το Τελευταίο Σήμα», γράψε ένα προσωρινό όνομα και δημιούργησε δωμάτιο.
2. Ο δεύτερος παίκτης ανοίγει `http://localhost:8080` στον ίδιο υπολογιστή ή χρησιμοποιεί ξεχωριστό προφίλ browser. Επιλέγει την ίδια αποστολή, γράφει το όνομά του και τον κωδικό που εμφανίζεται στη βάρδιά σου.
3. Στο φυλάκιο, συγκρίνετε τις συντεταγμένες του αρχείου με τα σημεία του χάρτη. Το σωστό στίγμα εμφανίζεται στο κοινό σημειωματάριο και των δύο παικτών.
4. Παίξτε το μηχανοστάσιο ή ανοίξτε τον ασύρματο. Στον ασύρματο, πείτε ο ένας στον άλλον το σήμα που βλέπετε και καταχωρίστε ο καθένας το σήμα του συμπαίκτη σας. Μετά τις δύο επιβεβαιώσεις, το μήνυμα εμφανίζεται στο κοινό σημειωματάριο.
5. Όταν βρεθούν και τα τρία στοιχεία, ανοίξτε το φανάρι και καταχωρίστε το στίγμα, την τροφοδοσία σε volt και το μήνυμα. Όταν ανάψει, και οι δύο παίκτες βλέπουν την ώρα ολοκλήρωσης και τη συνολική διάρκεια από τη δημιουργία του δωματίου.

Κάθε δωμάτιο χωρά δύο παίκτες. Η ανανέωση της σελίδας διατηρεί τη συμμετοχή στο ίδιο προφίλ και URL. Τα δωμάτια και η πρόοδος χάνονται με την επανεκκίνηση του τοπικού server.

Το φυλάκιο στο demo λειτουργεί χωρίς σύνδεση στις δημόσιες πηγές. Οι συντεταγμένες του προέρχονται από το επαληθευμένο snapshot. [Πηγές του φυλακίου](docs/snapshots/README.md)

Για δοκιμή της ζωντανής ανάκτησης, όρισε `ESCAPEHUB_LIVE_ARCHIVE=true` πριν εκκινήσεις τον server ή πέρασέ το με `-e ESCAPEHUB_LIVE_ARCHIVE=true` στο `docker run`. Σε αυτή τη λειτουργία ο server ανακτά μία φορά κατά την εκκίνηση τις συντεταγμένες από το Wikidata και τις περνά στο Nominatim. Αν η ανάκτηση αποτύχει, η εκκίνηση αναφέρει το σφάλμα.

#### Demo API

- `POST /api/room` δέχεται form με `name` και προαιρετικό `code`. Η δημιουργία επιστρέφει `201`, η συμμετοχή `200` και ένα γεμάτο δωμάτιο `409`. Η συμμετοχή αποθηκεύεται σε HttpOnly cookie.
- `GET /api/engine-room` επιστρέφει την κοινή κατάσταση (`code`, `players`, `revision`, `steps`, `solved`, `power`, `message`, `location`, `lanternReady`, `lanternLit`). Χωρίς συμμετοχή επιστρέφει `401`. Τα `power`, `message` και `location` αποκαλύπτονται όταν λυθούν οι αντίστοιχοι γρίφοι.
- Η κοινή κατάσταση περιλαμβάνει και `completion`. Έχει τιμή `null` μέχρι να ανάψει ο φάρος, οπότε περιέχει `completedAt` σε UTC και `durationSeconds` από τη δημιουργία του δωματίου. Η πρώτη επιτυχία καταγράφει τις τιμές και τυχόν επόμενες υποβολές τις διατηρούν.
- `POST /api/engine-room` δέχεται form με `action` και το `revision` που είδε ο παίκτης. Αν έχει αλλάξει η πρόοδος, επιστρέφει `409` μαζί με την τρέχουσα κατάσταση. Τα POST απαιτούν ίδιο origin.
- `GET /api/radio` δείχνει το προσωπικό σήμα του συνδεδεμένου παίκτη και τις επιβεβαιώσεις. Το `POST /api/radio` δέχεται το `signal` του συμπαίκτη και επιστρέφει `409` όσο λείπει δεύτερος παίκτης ή `422` για λάθος σήμα.
- `GET /api/archive` δείχνει τις συντεταγμένες του αρχείου και τα σημεία του χάρτη. Το `POST /api/archive` δέχεται το `marker` που επέλεξε ο παίκτης και επιστρέφει την κοινή κατάσταση με `422` για λάθος επιλογή ή `200` όταν έχει βρεθεί το στίγμα.
- `POST /api/lantern` δέχεται `location`, `power` (π.χ. `240`, `240V` ή `240 V`) και `message`. Επιστρέφει την κοινή κατάσταση με `409` πριν βρεθούν και τα τρία ευρήματα, `422` για λανθασμένη λύση ή `200` όταν ανάψει ο φάρος.

#### Λογαριασμοί

Ο σύνδεσμος «Δημιούργησε λογαριασμό» στην αρχική οθόνη ανοίγει τη φόρμα εγγραφής. Οι λογαριασμοί διατηρούνται μετά την επανεκκίνηση. Η είσοδος με λογαριασμό και η πρόοδος ανά παίκτη ανήκουν σε επόμενα stories.

- `POST /api/accounts` δέχεται form με `username` (3–24 λατινικά γράμματα, ψηφία, `_` ή `-`) και `password` (8–128 χαρακτήρες Unicode, χωρίς χαρακτήρες ελέγχου ή μόνο κενά). Επιστρέφει `201` με `{"username": ...}`, `400` για μη έγκυρα στοιχεία, `409` για υπάρχον όνομα ανεξαρτήτως πεζών/κεφαλαίων, `413` για form άνω των 2 KiB ή `503` αν η εγγραφή δεν μπορεί να αποθηκευτεί.
- Ο κωδικός αποθηκεύεται μόνο ως PBKDF2-HMAC-SHA256 hash με τυχαίο salt και 600.000 επαναλήψεις. Το `ESCAPEHUB_ACCOUNTS_FILE` ορίζει το αρχείο λογαριασμών. Η προεπιλογή είναι `.data/accounts.tsv` τοπικά και `/var/lib/escapehub/accounts.tsv` στο container. Το Compose χρησιμοποιεί μόνιμο volume. Χρησιμοποίησε ένα αρχείο ανά ενεργή διεργασία EscapeHub, σε ιδιωτικό φάκελο με δικαιώματα εγγραφής και υποστήριξη ατομικής μετονομασίας.
